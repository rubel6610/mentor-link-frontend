# 🎓 MentorLink Frontend

MentorLink is a premium 1-on-1 tutoring marketplace that connects passionate learners with expert mentors. This repository contains the **Next.js** frontend, featuring a stunning, responsive UI designed for a seamless learning experience.

## ✨ New & Unique Features

### 🌟 Skill Explorer (Interactive)
- **GSAP Powered:** A visually stunning category browser that uses staggered animations to showcase tutoring subjects.
- **Dynamic Discovery:** Automatically pulls live categories from the backend, allowing students to explore niches with a modern, interactive interface.

### 📊 Platform Stats (Real-time Feel)
- **Animated Counters:** Showcases platform impact through animated statistics (Mentors, Lessons, Success Stories).
- **Social Proof:** Builds instant trust with new users by highlighting the scale of the MentorLink community.

## 🚀 Key Features

### 👤 For Students
- **Browse & Search:** Find tutors by subject, rating, and price.
- **Instant Booking:** Schedule sessions with a real-time availability check.
- **Learning Dashboard:** Track upcoming sessions and view completed lesson history.
- **Reviews & Ratings:** Leave feedback for tutors after completed sessions.

### 👨‍🏫 For Tutors
- **Profile Customization:** Set hourly rates, experience, and expert categories.
- **Availability Management:** Define weekly time slots for student bookings.
- **Tutor Dashboard:** Monitor upcoming teaching sessions and student reviews.

### 🛡️ Admin Panel
- **User Management:** Oversee all students and tutors, with account status control.
- **Platform Analytics:** View total bookings, active users, and category distributions.

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v18+)
- npm or yarn

### 2. Installation
```bash
git clone https://github.com/rubel6610/mentorlink-frontend.git
cd mentorlink-frontend
npm install
```

### 3. Environment Setup
Create a `.env` file in the root directory:
```env
NEXT_PUBLIC_BASE_URL=http://localhost:5000/api
```

### 4. Run Development Server
```bash
npm run dev
```
